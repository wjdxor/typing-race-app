# 교실 타자 레이스

25명까지 동시에 참여할 수 있는 학교용 타자연습 게임입니다.

## 기능

- 학생은 참여코드와 이름으로 입장
- 교사는 비밀번호 `0121`로 방 생성
- 교사가 시작을 눌러야 학생들이 동시에 입력 가능
- 단어연습, 장문연습, 직접 입력 문제 지원
- 교사 화면에서 학생별 진행률, 정확도, 타수, 점수, 순위 실시간 확인

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 열면 됩니다.

## Vercel 배포

1. 이 폴더를 GitHub 저장소로 올립니다.
2. Vercel에서 해당 저장소를 Import 합니다.
3. Framework Preset은 Next.js로 두고 Deploy를 누릅니다.

이 버전은 외부 데이터베이스 없이 서버 메모리에 방 상태를 저장합니다. 간단한 수업 테스트와 데모에는 바로 쓸 수 있지만, 여러 반에서 동시에 장시간 운영하려면 Vercel KV, Redis, Supabase 같은 저장소를 붙이는 것을 권장합니다.
